# Arsound Desktop — releases

Downloads of Arsound Desktop (a free SoundCloud client for Windows 10/11 x64, no ads) live here as
zip files under **Releases**, on the right. This repository holds no source code; see `NOTICE.md`
for the terms the program and the zip are under.

**Private for now:** this is an early prototype, shared with a small group of testers by invitation.
It is not open to the public yet; the owner will say when that changes.

## Install

1. Download the zip from the latest release and unpack it anywhere (no installer).
2. Run `arsound.exe`.
3. Sign-in windows need the Microsoft Edge WebView2 Runtime (already on Windows 11 and most
   Windows 10 machines); the program points at the download page if it is missing.

## Updates

The program checks this repository's releases on its own (Settings, or the "Check for updates"
button); it only looks, it never downloads or installs anything by itself.
